use 裸命令拦截 + dotnet 验证超时档位（A+B）

实证（用户日志）：裸 use 漏进任务流跑 8 步；倒计时任务 dotnet run 冷编译 30s 卡线两次必败

A. UseCommandParser（Infrastructure 公共解析器）
- 裸 use / use --write 缺路径 → 命令层拦截打印用法，不进任务流
- ^use(\s|$) 锚定：不误伤 useful / 中文"使用"

B. RunCommandTool.ResolveTimeoutSeconds
- 沙箱模式仅 dotnet 验证命令 → 90s（对齐工程模式）；其余 30s 快速失败
- 超时后 Kill(entireProcessTree) 已有，无残留

[完成] 这个项目是一个基于 .NET 的本地 AI 工作台（Local AI Workbench），它提供了一个智能代理系统，用于执行各种任务，如代码生成、分析、修改等。以下是该项目的简要分析：



### 项目结构



1. **主程序入口**：

   - `src/Agent.Cli`：控制台应用程序入口点，负责命令行交互和初始化。

   - `src/Agent.Dashboard`：Web 界面，提供可视化任务监控和管理。



2. **核心功能模块**：

   - `src/Agent.Core`：包含核心抽象和模型定义。

   - `src/Agent.Infrastructure`：核心业务逻辑实现，包括代理循环、路由、工具执行等。



3. **测试模块**：

   - `tests/Agent.Infrastructure.Tests`：用于测试基础设施模块的功能。



### 核心特性



1. **任务执行引擎**：

   - 使用 Semantic Kernel (SK) 实现 ReAct 循环。

   - 支持三种模型角色（small、large、agent_pro），根据任务类型自动选择合适的模型。

   - 具备路由决策机制，将任务分发到不同的模型服务。



2. **工具系统**：

   - 提供多种工具，如文件读写、命令执行、代码分析等。

   - 工具支持工程感知和可写模式（通过 `--write` 参数启用）。



3. **记忆与状态管理**：

   - 模型级记忆系统，可以记住之前任务的发现和决策。

   - 工程上下文缓存，避免重复扫描项目文件。



4. **可视化界面**：

   - 提供 Web Dashboard，支持任务实时监控、历史任务查看、Diff 查看等功能。

   - 支持通过浏览器访问，方便用户进行交互式操作。



5. **安全机制**：

   - 使用 token 鉴权保护 Dashboard。

   - 工具调用拒绝记录，防止误操作。



### 技术栈



- **语言**：C#

- **框架**：.NET 10

- **依赖注入**：Microsoft.Extensions.DependencyInjection

- **AI 框架**：Semantic Kernel (SK)

- **Web 框架**：ASP.NET Core



该项目设计用于本地 AI 工作流，支持多种任务类型，并通过可视化界面提供良好的用户体验。
